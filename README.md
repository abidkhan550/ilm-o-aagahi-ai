# ilm-o-aagahi-ai
**Ilm-o-Aagahi AI** — Developed by Abid. An AI educational tutor powered by Streamlit &amp; Google Gemini. Ask questions via text or upload images/notes to receive step-by-step explanations in Urdu, Pashto, English, Arabic, Hindi, Spanish, or French. Features instant image analysis, multi-lingual responses, and a clean, user-friendly search UI.
